# Cross-prediction

Notebooks for {mod}`focal.cross_prediction` — stratifying uncommitted populations
for fate bias using cellular programs inferred from an intervention (for example a TF
knockout) against unperturbed controls.

This section is empty. The work currently lives outside the Python package, in
`SLIDE/Crossprediction.R` and `TF_Dynamic_Activity/` in the main repository, and lands
here when that module is ported.
